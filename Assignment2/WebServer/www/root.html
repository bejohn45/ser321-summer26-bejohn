You can make the following GET requests

  • /file/sample.html -- returns the content of the file sample.html
  • /json -- returns a json of the /random request
  • /random -- returns index.html
  • /multiply?num1=2&num2=5 -- returns result of multiplying num1 and num2
  • /github?query=users/bejohn45/repos -- returns public repository's full name, ID, and owner login
  • /compare?num1=2&num2=5 -- returns result of comparing num1 and num2 showing which is greater and difference
  • /repeat?text=hello&times=3 -- returns the text repeated the specified number of times
